# CREAR TABLA historial
historial — Registra el historial de acciones importantes que hacen los usuarios en el sistema (no cada movimiento, solo eventos clave de seguridad/administración: login, crear/desactivar usuario, cambiar rol, etc.). Sirve para poder responder después "¿quién hizo esto y cuándo?".
    id — identificador único del registro.
    usuario_id — FK a usuarios.id, quién realizó la acción.
    accion — qué se hizo (ej: "login", "creacion_usuario", "desactivacion_usuario", "cambio_rol").
    tabla_afectada — en qué tabla ocurrió el cambio (ej: "usuarios"), opcional.
    registro_id — id del registro específico afectado, opcional.
    detalle — texto describiendo qué cambió exactamente.
    fecha — cuándo ocurrió, se llena sola.



# CREAR TABLA TURNOS Y TURNO_ASIGNACIONES PARA ORDENAR Y ADMINISTRAR MEJOR LOS USUARIOS
turnos — Catálogo fijo de los turnos que existen (Mañana, Tarde, Noche), con su horario. Se crea una vez y casi no cambia.
    id
    nombre
    hora_inicio
    hora_fin

turno_asignaciones — Registro diario de qué operador trabaja en qué turno. Cambia todos los días y es lo que permite comparar "quién debía registrar algo" vs "quién sí lo hizo".
    id
    usuario_id (FK -> usuarios.id)
    turno_id (FK -> turnos.id)
    fecha
