MÓDULO: GESTIÓN DE MOLDES
=========================


Ruta 1: Registrar Molde
Endpoint: http://127.0.0.1:8000/api/moldes
Método: POST

JSON (Envía el Frontend):
{
    "nombre": "Molde A",
    "descripcion": "Descripción del molde",
    "numeroCamadas": 4,
    "numeroEnvases": 40,
    "numeroGruesas": 0.28
}

JSON (Respuesta en caso de éxito):
{
    "idMolde": 1,
    "nombre": "Molde A",
    "descripcion": "Descripción del molde",
    "numeroCamadas": 4,
    "numeroEnvases": 40,
    "numeroGruesas": 0.28
}

JSON (Respuesta en caso de error):
{
    "detail": "Error en la validación de los datos enviados"
}


---


Ruta 2: Editar Molde
Endpoint: http://127.0.0.1:8000/api/moldes/{id_molde}
Método: PUT

JSON (Envía el Frontend):
{
    "nombre": "Molde A Actualizado",
    "descripcion": "Nueva descripción",
    "numeroCamadas": 5,
    "numeroEnvases": 50,
    "numeroGruesas": 0.35
}

JSON (Respuesta en caso de éxito):
{
    "idMolde": 1,
    "nombre": "Molde A Actualizado",
    "descripcion": "Nueva descripción",
    "numeroCamadas": 5,
    "numeroEnvases": 50,
    "numeroGruesas": 0.35
}

JSON (Respuesta en caso de error):
{
    "detail": "No se pudo actualizar porque el molde no fue encontrado."
}


---


Ruta 3: Listado de Moldes (Vista Principal)
Endpoint: http://127.0.0.1:8000/api/moldes
Método: GET

Estructura de los datos que recibirá:
[
    {
        "idMolde": 1,
        "nombre": "Molde A",
        "descripcion": "Descripción del molde",
        "numeroCamadas": 4,
        "numeroEnvases": 40,
        "numeroGruesas": 0.28
    },
    {
        "idMolde": 2,
        "nombre": "Molde B",
        "descripcion": null,
        "numeroCamadas": 6,
        "numeroEnvases": 60,
        "numeroGruesas": 0.42
    }
]


---


Ruta 4: Ver Molde por ID (Para Editar)
Endpoint: http://127.0.0.1:8000/api/moldes/{id_molde}
Método: GET

Estructura de los datos que recibirá:
{
    "idMolde": 1,
    "nombre": "Molde A",
    "descripcion": "Descripción del molde",
    "numeroCamadas": 4,
    "numeroEnvases": 40,
    "numeroGruesas": 0.28
}

JSON (Respuesta en caso de error):
{
    "detail": "El molde especificado no existe."
}
