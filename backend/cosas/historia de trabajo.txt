#MÓDULO: Historia de Trabajo de Decoración

#ENDPOINTS
POST /crear/historia-trabajo
GET /historial/historia-trabajo
GET /obtener_registro/historia-trabajo/{id}
PUT /editar/historia-trabajo/{id}
GET /exportar/historia-trabajo/{id}

#FUNCIONES

crear_historia_trabajo
- Recibe el JSON completo (cabecera + colores + estaciones + temperatura)
- Inserta la cabecera y obtiene el id generado
- Inserta las filas de colores, estaciones y temperatura apuntando a ese id
- Devuelve el id del registro creado

listar_historias_trabajo
- Consulta todos los registros de la cabecera
- Devuelve lista con los campos resumen (id, fecha, molde, maquina, tipo_decorado, revisado_por)

obtener_historia_trabajo
- Recibe el id_htd_cabecera
- Consulta la cabecera y todas sus tablas hijas
- Devuelve el registro completo (cabecera + colores + estaciones + temperatura)

editar_historia_trabajo
- Recibe el id_htd_cabecera y el JSON completo actualizado
- Actualiza los campos de la cabecera
- Borra y reinsserta las filas de colores, estaciones y temperatura
- Devuelve el id del registro editado

exportar_historia_trabajo
- Recibe el id_htd_cabecera
- Consulta el registro completo de la DB
- Abre la plantilla Word guardada en backend/plantillas/
- Llena el documento reemplazando por índice de celda con los datos del registro
- Devuelve el archivo .docx como respuesta de descarga
