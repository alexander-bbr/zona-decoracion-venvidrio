Ruta 1: Ingreso de Pintura (Registro)
Endpoint: http://127.0.0.1:8000/api/pintura/registro
Método: POST

JSON (Envía el Frontend):

json
{
  "idPinturaInventario": int (1 o 2),
  "proveedor": "String",
  "fechaRegistro": "2026-06-24",
  "unidadDeMedida": "String",
  "cantidadRegistrada": 100.00,
  "registradoPor": "String",
  "observaciones": "String"
}


JSON (Respuesta al Frontend en caso de exito ):

{
  "mensaje": "Registro ingresado con éxito",
  "id": 
}

JSON (Respuesta al Frontend en caso de error ):
{
  "detail": "Insumo no encontrado en inventario"
}

#GESTION DE USUARIOS

Ruta 1: Crear Usuario
Endpoint: [http://127.0.0.1:8000/api/usuarios](http://127.0.0.1:8000/api/usuarios)
Método: POST

JSON (Envía el Frontend):
{
"cedula": "String",
"carnetUsuario": "String",
"contrasena": "String",
"nombres": "String",
"apellidos": "String",
"telefono": "String",
"correo": "String",
"rol": "administrador" | "operador",
"activoUsuario": true,
"idsPermisos": [1, 2]
}

JSON (Respuesta en caso de éxito):
{
"mensaje": "Usuario creado con éxito",
"id": 1
}

JSON (Respuesta en caso de error):
#caso 1
{
"detail": "El carnet ya está registrado"
}

#caso 2
{
"detail": "La cédula ya está registrada"
}

#caso 3
{
"detail": "El correo ya está registrado"
}

"correo": "string",
"rol": "string",

},

{

}
