
MÓDULO: EXPORTACIÓN
===================


Ruta 1: Exportar Historial Gestión Productiva
Endpoint: http://127.0.0.1:8000/api/exportacion/gestion-productiva
Método: POST

JSON (Envía el Frontend):
{
    "fechaDesde": "2024-01-01",
    "fechaHasta": "2024-12-31"
}

Respuesta en caso de éxito:
Archivo .xlsx descargable con el historial de gestión productiva en el rango de fechas indicado.

Respuesta en caso de error:
{
    "detail": "No se encontraron registros en el rango de fechas indicado."
}
