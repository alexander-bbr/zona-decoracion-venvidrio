# Especificaciones

## Contexto general del proyecto

Es una una Aplicación para el Departamento de Decoración de la planta Venezolana del Vidrio (Venvidrio).

## Limitaciones

- Se deben usar estas tecnologías
  - React en su última versión
  - TypeScrit
  - Estilos en CSS modules
  - Vite (nada de Next.js)

- El tipado de TypeScript lo tienes que hacer en src/types/, en un archivo index.ts. No puedes usar interfaces, solo type

## Colores y estilos

Hazlo minimalista. Como paleta de colores usa algo elegante, minimalista, y profesional.

Los colores los colocaras en src/index.css como como variables CSS.
