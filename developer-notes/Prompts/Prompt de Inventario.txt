Estoy trabajando en una aplicación hecha en React + TS con Vite en el frontend y python y mysql en el backend. La aplicación ya tiene varios módulos listos, uno de ellos se llama Gestión de Justificantes. Basicamente es hay un archivo principal llamado GestionJustificantes donde se pueden ver todos los justificantes en una especie de tabla, y puedes presionar el botón de "+ Registrar Justificante" para añadir un nuevo justificante. Pero también, se puede hacer click en cualquiera de los registros de la tabla de GestionJustificantes para redirigirse al formulario de editar y editar ese justificante.

O sea, tengo 3 componentes, el GestionJustificantes.tsx, el RegistrarJustificante.tsx y EditarJustificante.tsx.

Este es el código de GestionJustificantes.tsx: import { useEffect, useState } from "react";
import { useNavigate, NavLink, useLocation, Outlet } from "react-router-dom";
import styles from "./gestion-justificantes.module.css";

type Justificante = {
  idJustificante: number;
  etiqueta: string;
  descripcion: string | null;
};

const API_JUSTIFICANTES = "http://127.0.0.1:8000/api/gestion-justificantes";

export const GestionJustificantes = () => {
  const navigate = useNavigate();
  const location = useLocation();
  const [justificantes, setJustificantes] = useState<Justificante[]>([]);
  const [cargando, setCargando] = useState(true);
  const [error, setError] = useState("");

  const cargarJustificantes = async () => {
    setCargando(true);
    setError("");
    try {
      const response = await fetch(API_JUSTIFICANTES);
      if (!response.ok) {
        throw new Error(`Error al cargar justificantes: ${response.status}`);
      }
      const data = await response.json();
      const justificantesNormalizados = data.map(
        (justificante: Justificante) => ({
          ...justificante,
          idJustificante: Number(justificante.idJustificante),
        }),
      );
      // Ordenar los justificantes por ID de forma ascendente
      const justificantesOrdenados = justificantesNormalizados.sort(
        (a, b) => a.idJustificante - b.idJustificante,
      );
      setJustificantes(justificantesOrdenados);
    } catch (loadError) {
      setError(
        loadError instanceof Error
          ? loadError.message
          : "Error al cargar justificantes.",
      );
    } finally {
      setCargando(false);
    }
  };

  // Cargar justificantes al montar el componente
  useEffect(() => {
    cargarJustificantes();
  }, []);

  // Recargar cuando la ruta cambie a la raíz (cuando volvemos de registrar/editar)
  useEffect(() => {
    if (location.pathname === "/gestion-justificantes") {
      cargarJustificantes();
    }
  }, [location.pathname]);

  const isRoot = location.pathname === "/gestion-justificantes";

  const getTitle = () => {
    const path = location.pathname;
    if (path.includes("registrar-justificante"))
      return "Registrar Justificante";
    if (path.includes("editar-justificante")) return "Editar Justificante";
    return "";
  };

  return (
    <section className={styles.container}>
      <header className={styles.moduleHeader}>
        <h2 className={styles.moduleTitle}>Gestión de Justificantes</h2>
        <p className={styles.moduleSubtitle}>
          {isRoot
            ? "Gestión del catálogo de justificantes"
            : "Gestión de Justificantes"}
        </p>
      </header>

      {!isRoot ? (
        <nav className={`${styles.subNav} content`} id="subNav">
          <NavLink
            to="/gestion-justificantes"
            className={({ isActive }) =>
              isActive
                ? `${styles.subNavLink} ${styles.active}`
                : styles.subNavLink
            }
          >
            ← Volver
          </NavLink>
          <span className={styles.subNavTitle}>{getTitle()}</span>
        </nav>
      ) : null}

      {isRoot ? (
        <section className={`${styles.gestionJustificantes} content`}>
          <section className={styles.controlPanel}>
            <h2 className={styles.title}>Listado de Justificantes</h2>
            <button
              className={styles.registerButton}
              onClick={() => navigate("registrar-justificante")}
            >
              + Registrar Justificante
            </button>
          </section>

          {cargando && (
            <p className={styles.loading}>Cargando justificantes...</p>
          )}
          {error && <p className={styles.error}>{error}</p>}
          {!cargando && !error && (
            <div className={styles.tableContainer}>
              {justificantes.length === 0 ? (
                <p className={styles.emptyMessage}>
                  No hay justificantes registrados.
                </p>
              ) : (
                <table className={styles.table}>
                  <thead>
                    <tr>
                      <th>Etiqueta</th>
                      <th>Descripción</th>
                    </tr>
                  </thead>
                  <tbody>
                    {justificantes.map((justificante) => (
                      <tr
                        key={justificante.idJustificante}
                        onClick={() =>
                          navigate(
                            `editar-justificante/${justificante.idJustificante}`,
                          )
                        }
                        className={styles.clickableRow}
                      >
                        <td>{justificante.etiqueta}</td>
                        <td>{justificante.descripcion || "—"}</td>
                      </tr>
                    ))}
                  </tbody>
                </table>
              )}
            </div>
          )}
        </section>
      ) : (
        <Outlet />
      )}
    </section>
  );
};

Este es el RegistrarJustificante.tsx: import { useState, type FormEvent } from "react";
import { useNavigate } from "react-router-dom";
import { HeaderForm } from "../../../components/HeaderForm";
import styles from "./registrar-justificante.module.css";

type FormData = {
  etiqueta: string;
  descripcion: string;
};

const API_JUSTIFICANTES = "http://127.0.0.1:8000/api/gestion-justificantes";

export const RegistrarJustificante = () => {
  const navigate = useNavigate();
  const [formData, setFormData] = useState<FormData>({
    etiqueta: "",
    descripcion: "",
  });
  const [error, setError] = useState("");
  const [cargando, setCargando] = useState(false);

  const handleChange = (
    e: React.ChangeEvent<HTMLInputElement | HTMLTextAreaElement>,
  ) => {
    const { name, value } = e.target;
    setFormData((prev) => ({
      ...prev,
      [name]: value,
    }));
  };

  const handleSubmit = async (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    setError("");
    setCargando(true);

    // Validaciones
    if (!formData.etiqueta.trim()) {
      setError("La etiqueta del justificante es obligatoria.");
      setCargando(false);
      return;
    }

    try {
      const response = await fetch(API_JUSTIFICANTES, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(formData),
      });

      if (!response.ok) {
        const data = await response.json().catch(() => null);
        throw new Error(
          data?.detail ?? `Error al registrar justificante: ${response.status}`,
        );
      }

      navigate("/gestion-justificantes");
    } catch (submitError) {
      setError(
        submitError instanceof Error
          ? submitError.message
          : "Error al registrar justificante.",
      );
    } finally {
      setCargando(false);
    }
  };

  const handleReset = () => {
    setFormData({
      etiqueta: "",
      descripcion: "",
    });
    setError("");
  };

  return (
    <form className={`${styles.form} content`} onSubmit={handleSubmit}>
      <HeaderForm />

      <h3 className={styles.title}>Registrar Nuevo Justificante</h3>

      <section className={styles.formData}>
        <fieldset className={styles.fieldset}>
          <legend className={styles.legend}>Datos del Justificante</legend>

          <div className={styles.inputWrapper}>
            <label htmlFor="etiqueta">
              Etiqueta <span className={styles.requireSymbol}>*</span>
            </label>
            <input
              id="etiqueta"
              name="etiqueta"
              type="text"
              value={formData.etiqueta}
              onChange={handleChange}
              placeholder="Ej: Desperfecto en el Decorado"
              required
            />
          </div>

          <div className={styles.inputWrapper}>
            <label htmlFor="descripcion">
              Descripción <span className={styles.requireSymbol}>*</span>
            </label>
            <textarea
              id="descripcion"
              name="descripcion"
              value={formData.descripcion}
              onChange={handleChange}
              placeholder="Descripción detallada del justificante"
              rows={6}
              required
            />
          </div>
        </fieldset>

        {error && <p className={styles.error}>{error}</p>}

        <div className={styles.buttonWrapper}>
          <button
            type="submit"
            className={styles.saveButton}
            disabled={cargando}
          >
            {cargando ? "Registrando..." : "Guardar"}
          </button>
          <button
            type="button"
            className={styles.resetButton}
            onClick={handleReset}
            disabled={cargando}
          >
            Resetear
          </button>
        </div>
      </section>
    </form>
  );
};

Y este es el EditarJustificante.tsx: import { useEffect, useState, type FormEvent } from "react";
import { useNavigate, useParams } from "react-router-dom";
import { HeaderForm } from "../../../components/HeaderForm";
import styles from "./editar-justificante.module.css";

type Justificante = {
  idJustificante: number;
  etiqueta: string;
  descripcion: string | null;
};

type FormData = {
  etiqueta: string;
  descripcion: string;
};

const API_JUSTIFICANTES = "http://127.0.0.1:8000/api/gestion-justificantes";

export const EditarJustificante = () => {
  const { id } = useParams<{ id: string }>();

  if (!id) {
    return <p className={styles.error}>ID de justificante inválido.</p>;
  }

  return <CargarJustificante idJustificante={id} />;
};

const CargarJustificante = ({ idJustificante }: { idJustificante: string }) => {
  const navigate = useNavigate();
  const [formData, setFormData] = useState<FormData>({
    etiqueta: "",
    descripcion: "",
  });
  const [cargando, setCargando] = useState(true);
  const [error, setError] = useState("");
  const [guardando, setGuardando] = useState(false);

  useEffect(() => {
    const cargarJustificante = async () => {
      setCargando(true);
      setError("");
      try {
        const response = await fetch(`${API_JUSTIFICANTES}/${idJustificante}`);
        if (!response.ok) {
          const data = await response.json().catch(() => null);
          throw new Error(
            data?.detail ??
              (response.status === 404
                ? "El Justificante especificado no existe."
                : `Error al cargar justificante: ${response.status}`),
          );
        }
        const justificante = (await response.json()) as Justificante;
        setFormData({
          etiqueta: justificante.etiqueta,
          descripcion: justificante.descripcion || "",
        });
      } catch (loadError) {
        setError(
          loadError instanceof Error
            ? loadError.message
            : "Error al cargar justificante.",
        );
      } finally {
        setCargando(false);
      }
    };
    void cargarJustificante();
  }, [idJustificante]);

  const handleChange = (
    e: React.ChangeEvent<HTMLInputElement | HTMLTextAreaElement>,
  ) => {
    const { name, value } = e.target;
    setFormData((prev) => ({
      ...prev,
      [name]: value,
    }));
  };

  const handleSubmit = async (event: FormEvent<HTMLFormElement>) => {
    event.preventDefault();
    setError("");
    setGuardando(true);

    // Validaciones
    if (!formData.etiqueta.trim()) {
      setError("La etiqueta del justificante es obligatoria.");
      setGuardando(false);
      return;
    }

    try {
      const response = await fetch(`${API_JUSTIFICANTES}/${idJustificante}`, {
        method: "PUT",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(formData),
      });

      if (!response.ok) {
        const data = await response.json().catch(() => null);
        throw new Error(
          data?.detail ??
            `Error al actualizar justificante: ${response.status}`,
        );
      }

      navigate("/gestion-justificantes");
    } catch (submitError) {
      setError(
        submitError instanceof Error
          ? submitError.message
          : "Error al actualizar justificante.",
      );
    } finally {
      setGuardando(false);
    }
  };

  const handleReset = async () => {
    try {
      const response = await fetch(`${API_JUSTIFICANTES}/${idJustificante}`);
      if (response.ok) {
        const justificante = (await response.json()) as Justificante;
        setFormData({
          etiqueta: justificante.etiqueta,
          descripcion: justificante.descripcion || "",
        });
      }
    } catch {
      // Ignorar errores en reset
    }
    setError("");
  };

  if (cargando) {
    return <p className={styles.loading}>Cargando justificante...</p>;
  }

  return (
    <form className={`${styles.form} content`} onSubmit={handleSubmit}>
      <HeaderForm />

      <h3 className={styles.title}>Editar Justificante #{idJustificante}</h3>

      <section className={styles.formData}>
        <fieldset className={styles.fieldset}>
          <legend className={styles.legend}>Datos del Justificante</legend>

          <div className={styles.inputWrapper}>
            <label htmlFor="etiqueta">
              Etiqueta <span className={styles.requireSymbol}>*</span>
            </label>
            <input
              id="etiqueta"
              name="etiqueta"
              type="text"
              value={formData.etiqueta}
              onChange={handleChange}
              placeholder="Ej: Desperfecto en el Decorado"
              required
            />
          </div>

          <div className={styles.inputWrapper}>
            <label htmlFor="descripcion">
              Descripción <span className={styles.requireSymbol}>*</span>
            </label>
            <textarea
              id="descripcion"
              name="descripcion"
              value={formData.descripcion}
              onChange={handleChange}
              placeholder="Descripción detallada del justificante"
              rows={6}
              required
            />
          </div>
        </fieldset>

        {error && <p className={styles.error}>{error}</p>}

        <div className={styles.buttonWrapper}>
          <button
            type="submit"
            className={styles.saveButton}
            disabled={guardando}
          >
            {guardando ? "Actualizando..." : "Actualizar"}
          </button>
          <button
            type="button"
            className={styles.resetButton}
            onClick={handleReset}
            disabled={guardando}
          >
            Resetear
          </button>
        </div>
      </section>
    </form>
  );
};

NOTA TÉCNICA DE PAGINACIÓN:

Este endpoint es de tipo GET. Por lo tanto, los valores de paginación NO se envían 
en el cuerpo de la petición (como un POST o un JSON), sino directamente en la 
URL como PARÁMETROS DE CONSULTA (Query Parameters).

- ¿Cómo los recibe el backend?
  El backend los captura automáticamente de la URL mediante los argumentos 
  'skip' y 'limit' configurados en la función de Python.

- Comportamiento y Valores por Defecto:
  1. Si el frontend hace la petición limpia sin enviar nada (ej. GET /produccion/), 
     el backend asume por defecto 'skip=0' y 'limit=50', devolviendo automáticamente 
     los primeros 50 registros.
  2. Cuando el usuario navega a otra página, el frontend debe agregarlos a la URL 
     especificando cuántos registros se salta ('skip') y el tope ('limit').

- Ejemplos de uso desde el Frontend (Cliente):
  * Página 1 (Primeros 50 registros):  GET /historial+movimiento?skip=0&limit=50
  * Página 2 (Siguientes 50 registros): GET /historial+movimiento?skip=50&limit=50
  * Página 3 (Siguientes 50 registros): GET /historial+movimiento?skip=100&limit=50

- Fórmula general para calcular el skip en el frontend según el número de página:
  skip = (numero_de_pagina - 1) * 50


NOTA TÉCNICA N°2 DE LA RESPUESTA:

Este Endpoint deberá regresar los 50 primeros registros entre ambas tablas, o sea, basándose en el campo fecha. Esto quiere decir, que puede que regresa 25 de registro y 25 de salida; o 43 de registro y 7 de salida, etc.
