MÓDULO: EXPORTACIÓN
=========================



Ruta 1: Exportar Historial Gestión Productiva
Endpoint: http://127.0.0.1:8000/api/exportacion/gestion-productiva
Método: POST

JSON (Envía el Frontend):
{
    "fechaDesde": "2024-01-01",
    "fechaHasta": "2024-12-31"
}

Respuesta en caso de éxito:
Archivo .xlsx descargable con el historial de gestión productiva en el rango de fechas indicado.

Respuesta en caso de error:
{
    "detail": "No se encontraron registros en el rango de fechas indicado."
}

NOTA TÉCNICA: Este endpoint es diferente a los demás, aquí a demás del rango de fechas, es posible que se le pase un valor adicional en el cuerpo, que es el de critero. Es UN SOLO criterio, no varios a la vez.

Estos criterios pueden ser los siguientes:

- tecnico = DANIEL PÉREZ (string - SIEMPRE se debe mandar en mayúsculas)
- turno = 1 (number)
- totalGruesas = 694.03 (decimal)
- totalGruesasLisas = 15.08 (decimal)
- totalGruesasDecoradas = 610.3 (decimal)
- eficiencia = 87,23 (decimal)
- item = THXI (string)

Ejemplo: 

JSON (Envía el Frontend):
{
    "fechaDesde": "2024-01-01",
    "fechaHasta": "2024-12-31"
    "totalGruesasLisas": 15.08,
}

Ejemplo 2:

JSON (Envía el Frontend):
{
    "fechaDesde": "2024-01-01",
    "fechaHasta": "2024-12-31"
    "tecnico": "DANIEL PÉREZ",
}

Ruta 8: Exportar Rendimiento por Molde
Endpoint: http://127.0.0.1:8000/api/exportacion/rendimiento-moldes
Método: POST

JSON (Envía el Frontend):
{
    "fechaDesde": "2024-01-01",
    "fechaHasta": "2024-12-31"
}

Respuesta en caso de éxito:
Archivo .xlsx descargable con el rendimiento (entradas en gruesas, gruesas lisas, decoradas, defectuosas, eficiencia y deficiencia) por cada molde en el rango de fechas indicado.

Respuesta en caso de error:
{
    "detail": "No se encontraron moldes con producción o activos en el rango de fechas indicado."
}
