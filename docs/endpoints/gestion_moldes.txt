MÓDULO: GESTIÓN DE MOLDES
=========================


Ruta 1: Registrar Molde
Endpoint: http://127.0.0.1:8000/api/gestion-moldes
Método: POST

JSON (Envía el Frontend):
{   
    "item" : "THXI",
    "nombre": "Molde A",
    "descripcion": "Descripción del molde",
    "numeroCamadas": 4,
    "numeroEnvases": 40,
    "numeroGruesas": 0.28,
    "estado": true # boolean
}

JSON (Respuesta en caso de éxito):
{
    "status": "Registro insertado con éxito",
    "item" : "THXI"
}

JSON (Respuesta en caso de error):
{
    "detail": "Error en la validación de los datos enviados"
}

JSON (Respuesta en caso de error):
{
    "detail": "Ya existe un molde con ese item."
}

NOTA TÉCNICA: Se puede editar el item, pero se verifica en el backend si no existe ya un molde con el mismo item

---


Ruta 2: Editar Molde
Endpoint: http://127.0.0.1:8000/api/gestion-moldes/{item}
Método: PUT

JSON (Envía el Frontend):
{   
    "item" : "THXI",
    "nombre": "Molde A Actualizado",
    "descripcion": "Nueva descripción",
    "numeroCamadas": 5,
    "numeroEnvases": 50,
    "numeroGruesas": 0.35,
    "estado": true # boolean
}

JSON (Respuesta en caso de éxito):
{
    "status": "Registro actualizado con éxito",
    "item" : "THXI"
}

JSON (Respuesta en caso de error):
{
    "detail": "No se pudo actualizar porque el molde no fue encontrado."
}

JSON (Respuesta en caso de error):
{
    "detail": "Ya existe un molde con ese item."
}

NOTA TÉCNICA: Se puede editar el item, pero se verifica en el backend si no existe ya un molde con el mismo item

---
