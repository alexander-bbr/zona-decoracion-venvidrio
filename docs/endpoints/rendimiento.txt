
Ruta 1: Lisos por Fecha
Endpoint: http://127.0.0.1:8000/api/rendimiento/lisos
Método: GET

Parámetros de consulta: desde, hasta
Ejemplo: http://127.0.0.1:8000/api/rendimiento/lisos?desde=2026-09-01&hasta=2026-09-30

Estructura de los datos que recibirá:
{
    "registrosLisos": [
        {"fecha": "2026-09-08", "totalEnvasesLisos": 1800, "totalGruesasLisas": "6.24"},
        {"fecha": "2026-09-09", "totalEnvasesLisos": 3200, "totalGruesasLisas": "11.50"}
    ],
    "totalEnvasesLisos": 5000,
    "totalGruesasLisas": "17.74"
}

JSON (Respuesta en caso de error):
{
    "detail": "No se encontraron registros en el rango de fechas indicado."
}

Ruta 7: Agregar meta
Endpoint: http://127.0.0.1:8000/api/rendimiento/metas
Método: POST

JSON (Envía el Frontend):
{
    "anio": 2026,
    "mes": "octubre",
    "deficiencia": "89",
    "estado" : true         # Boolean 
}

JSON (Respuesta en caso de éxito):
{
    "status": "Meta registrada con éxito",
    "id": 1
}



JSON (Respuesta en caso de error):
{
    "detail": "Error al registrar la meta"
}

JSON (Respuesta en caso de conflicto):
{
    "detail": "Ya existe una meta para ese año y mes."
}

Ruta 9: Editar Meta
Endpoint: http://127.0.0.1:8000/api/rendimiento/{id_meta}
Método: PUT

JSON (Envía el Frontend):
{
    "anio": 2026,
    "mes": "enero",
    "deficiencia": 93
    "estado": true # boolean
}

JSON (Respuesta en caso de éxito):
{
    "status": "Meta actualizada con éxito",
    "id": 1
}

JSON (Respuesta en caso de error):
{
    "detail": "No se pudo actualizar porque la meta no fue encontrada."
}

JSON (Respuesta en caso de conflicto):
{
    "detail": "Ya existe una meta para ese año y mes."
}
